# NCBI Datasets Package for Monkeypox virus (taxon: monkeypox)

This package was downloaded using the NCBI Datasets command line tool:
`datasets download virus genome taxon monkeypox --filename monkeypox.zip`

## Package Contents:
- `README.md`: This summary file
- `md5sum.txt`: MD5 checksums for the archive contents
- `ncbi_dataset/data/dataset_catalog.json`: File catalog describing package assemblies
- `ncbi_dataset/data/data_report.jsonl`: JSON Lines report containing taxonomic and metadata records
- `ncbi_dataset/data/genomic.fna`: Genomic nucleotide FASTA sequences for Monkeypox virus
